lv.an.pc.s4Text
  en: With a graphics card, add <code>--gpu</code>. This needs a GPU program: <code>yskar-cuda</code> for NVIDIA cards, <code>yskar-opencl</code> for AMD and Intel cards. The miner takes the first one that finds a card; <code>--gpu-api opencl</code> uses the AMD and Intel program even if an NVIDIA card is present. For Linux both are attached to every Node Core release (<code>yskar-cuda-…-linux-x86_64</code>, <code>yskar-opencl-…-linux-x86_64</code>); on Windows, build them as described in the repository under <code>node-core/gpu</code>.
  tr: Ekran kartın varsa <code>--gpu</code> ekle. Bunun için bir GPU programı gerekir: NVIDIA kartları için <code>yskar-cuda</code>, AMD ve Intel kartları için <code>yskar-opencl</code>. Madenci kart bulan ilk programı kullanır; <code>--gpu-api opencl</code> NVIDIA kartı takılı olsa bile AMD ve Intel programını seçer. Linux için ikisi de her Node Core sürümüne eklenir (<code>yskar-cuda-…-linux-x86_64</code>, <code>yskar-opencl-…-linux-x86_64</code>); Windows’ta depoda <code>node-core/gpu</code> altında anlatıldığı gibi derle.
