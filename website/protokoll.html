Anatomy of a block header

Every block starts with exactly 136 bytes. Its hash is double SHA-256 over these bytes, and it must not exceed the target that the difficulty sets.

ver4 height4 prevHash32 merkleRoot32 stateRoot32 time8 diff4 txs4 extra8 nonce8
prevHashThe hash of the previous block. It links the chain: changing an old block would change every hash after it.
merkleRootOne hash over all transactions in the block. A single changed byte in any transfer changes it.
stateRootOne hash over all accounts (balance and nonce) after this block. Every node computes it itself and compares.
nonceThe number miners vary. The first 128 bytes stay the same for a job, so each try needs only two SHA-256 compression steps.

Anatomy of a transfer

A transfer moves YSR from one account to another. It is 168 bytes plus an optional memo.

meta8 from20 to20 amt8 fee8 nonce8 key32 signature64
  • The signature also covers the chain ID, so a transfer signed for YSKAR is invalid on any other network.
  • The nonce counts the transfers an account has sent. The same transfer can never be applied twice.
  • An optional expiry height lets a transfer lapse if it has not been included by then.

Issuance by era

An era lasts 12,000 blocks, about 83 days. In each era the reward is half of the one before. From block 444,000 no new YSR are created and miners receive the fees only.
