YSKAR Node Core

Node, wallet and mining in one program. Node Core checks every block itself, keeps your YSR and mines with your processor and NVIDIA graphics card.

  • Install and start – no command line
  • The same 12 words as in the app
  • Solo, in a pool, or run a pool of your own

Full node

Run your own node

A node checks every block itself, starting from block 0. The more nodes there are, the less YSKAR depends on any single computer. A Raspberry Pi is enough.

  • Node.js 22 or newer
  • Runs on Linux, Windows and macOS
  • Can run its own pool, no sign-up needed

Frequently asked questions

Does it cost anything to take part?

No. The app, Mini App and miner are free. You only pay for the electricity your device uses.

What if I lose my phone?

With your 12 words you can restore your wallet on any device. Without them, nobody can recover the funds, not even us.

Why doesn’t the Play Store app mine?

Google Play does not allow apps that mine cryptocurrency on the device itself. That is why the Android app with mining is available directly on this website.

Is the code open?

Yes. The entire code – node, app, miner and this website – is public on GitHub.

How do I know the numbers are real?

The explorer checks every block in your browser, and anyone can run a full node that verifies the entire chain from block 0.
