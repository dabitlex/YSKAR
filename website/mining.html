Mine YSR

New YSR come only from mining. Phones, PCs and graphics cards compute SHA-256d, and every block found pays the miners behind it directly. Pick a way, see what your device would find and choose a pool.

The halving falls within the next 30 days; the 30-day value is therefore set too high.

Network hashrate is the work of the last 100 blocks divided by their time. A pool’s share is how many of these blocks it actually found; the hashrate a pool reports itself is not used.

This is an estimate, not a promise. Blocks are found by chance, the difficulty follows the whole network and the network hashrate changes all the time. Fees are not included. Values in YSR only.
