Mine

Lend it your machine.

New YSR come from mining and from nowhere else. A phone, a PC or a graphics card can take part, alone or in a pool.

The screen shows sample data.

Everyone guesses at once.

Right now the whole network works at about : billions of numbers every second, all hunting for the same block.

One number fits.

About every ten minutes one machine finds a number that works. That is a new block, and the search starts again.

The block pays everyone who helped.

In a pool the reward is split by the work each miner delivered and paid inside the block itself. The newest pool block paid addresses at once.

No account. No payout threshold. No custody.

A YSKAR pool is not a service with accounts. It is a node whose blocks pay every miner directly, in the block itself. The operator never holds anyone else's coins, and there is no payout threshold.

Mining is guessing, very fast.

Press start and this device joins in for a moment. It takes the newest block and searches for a number that makes its hash begin with enough zeros: the same search every miner runs, at practice difficulty.

Choose your setup

Every way is free and uses the same wallet: with your 12 words you reach the same YSR everywhere.

Node Core for Windows and Linux

A full node, a wallet and a miner in one program. Node Core checks every block itself and mines with your processor and with graphics cards from NVIDIA, AMD and Intel. Version 1.1.0, for Windows 10 and 11 and for 64-bit Linux.

  1. Download the installer and run it.
  2. Create a wallet and write down the 12 words, or bring your wallet over with them.
  3. Under Mining, choose solo or a pool, pick processor or graphics card, and start.
Download for Windows Download for Linux (.deb)

Also available: an AppImage for other Linux distributions, and the release notes with checksums.

The Windows installer is not signed. Windows therefore asks once: choose “More info”, then “Run anyway”. Compare the checksum with the release notes if you want to be sure the file is the published one.

On your phone

The easiest way to get to know YSKAR. A phone contributes little hash power and finds blocks only in a pool. Serious mining runs on PCs and rigs.

  1. Install the Android app from GitHub, or open the Mini App in Telegram.
  2. Create a wallet and write down the 12 words on paper.
  3. Choose a pool and start mining.
Android app with mining Mini App in Telegram
Android app
Keeps mining in the background, also with the screen locked, and shows the status in a home-screen widget. Distributed as an APK, because app stores do not allow on-device mining.
Mini App
Nothing to install. Runs inside Telegram while it is open. Your coins depend on your 12 words, not on your Telegram account.
YSKAR Wallet
The wallet app does not mine. It is made for sending, receiving and signing.

The command-line miner

For Windows, macOS and Linux. The miner needs only an address: no key, no wallet and no sign-up. You can run it on a computer you do not control.

Needs
Node.js 20 or newer, nothing else to install
Graphics cards
add --gpu. It uses yskar-cuda for NVIDIA and yskar-opencl for AMD and Intel
Solo
mine against your own full node and leave out --mode pool
The full guide to the miner 
# get the miner and test this computer
git clone https://github.com/dabitlex/YSKAR.git
cd YSKAR/miner
node src/selbsttest.mjs

# mine in the public pool
node src/cli.mjs --address ysr1... --api https://pool.yskar.app --mode pool

# or solo, against your own node
node src/cli.mjs --address ysr1... --api http://127.0.0.1:8645

Replace ysr1... with your own address. Rewards go straight to it.

The pools, live

Solo, you search alone and keep the whole reward of a block you find. In a pool, many search together and the reward is split by the work each one delivered.

Accounting
By the shares of the recent past (PPLNS). If you have only just started, your part of the first block is small.
Seats
A block can pay at most 64 addresses, so a pool has 63 seats plus the operator's fee. From revision 6 it is 254.
Fee
Set by the operator, between 0 and 5 %.
Your own pool
Any node can be a pool, without registration. How to run one

Nobody can promise you a return. How often you receive something depends on your hash power, on the power of the whole network and on chance. YSR has no market price.
