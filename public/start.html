Kein Spiel, das so tut als ob

Es gibt viele Apps, in denen man auf einen Knopf tippt und eine Zahl hochzählt. YSKAR ist etwas anderes: Dein Telefon rechnet echte SHA-256-Hashes, so wie es ein Bitcoin-Miner tut. Der Server prüft jeden einzelnen davon nach, und jeder gefundene Block liegt offen im Explorer.

Dahinter steht eine eigene Blockchain, nicht ein Punktestand in einer Datenbank. Sie hat einen Genesis-Block, Transaktionen, Signaturen und eine Difficulty, die sich an die Rechenleistung des Netzes anpasst. Wer einen Block findet, bekommt den Reward per Coinbase-Transaktion direkt auf seine Adresse.

Der Genesis-Block trägt eine Inschrift, und sie ist der Anspruch an alles Weitere:

proof, not promise

Was beim Minen passiert

Mining heißt: so lange Zahlen durchprobieren, bis ein Hash herauskommt, der klein genug ist. Es gibt keine Abkürzung, nur Rechenarbeit.

  1. Dein Gerät bekommt eine Aufgabe

    Der Knoten stellt einen Blockentwurf zusammen und schickt ihn an dein Telefon, zusammen mit dem Ziel, das der Hash unterbieten muss.

  2. Es probiert Zahlen durch

    Millionen pro Sekunde. Für jede wird der Block zweimal mit SHA-256 gehasht. Gerechnet wird in WebAssembly, damit ein Telefon mithalten kann.

  3. Treffer werden eingereicht

    Findet dein Gerät einen Hash unter dem Ziel, schickt es nur die gefundene Zahl. Der Server rechnet den Hash selbst nach — er glaubt keiner Angabe deines Geräts.

  4. Ein guter Treffer ist ein Block

    Unterbietet der Hash nicht nur dein persönliches Ziel, sondern das der ganzen Kette, ist es ein Block. Der Reward geht direkt an deine Adresse, und die Kette wächst um einen Eintrag.

Glaub uns nichts

Der Name der Kette ist ein Versprechen, das man einlösen können muss. Deshalb ist alles so gebaut, dass du es selbst prüfen kannst.

Der Block Explorer lädt die Blöcke und rechnet sie in deinem Browser nach: Er setzt die 136 Header-Bytes aus den Einzelfeldern neu zusammen, hasht sie doppelt mit SHA-256, prüft das Ergebnis gegen die eingetragene Difficulty und ob jeder Block auf seinen Vorgänger zeigt. Keine dieser Aussagen stammt vom Server.

Der Quelltext liegt offen. Wer möchte, kann einen eigenen Beobachter-Knoten betreiben, der die ganze Kette von Block 0 an nachrechnet — auf einem Raspberry Pi genügt das.

Die 875 YSR des ersten Blocks gingen an eine Adresse aus lauter Nullbytes. Es gibt keinen Schlüssel dafür — niemand hat vorab etwas bekommen.

Wie viel es gibt

21 Millionen YSR, nicht mehr. Diese Zahl ist keine Einstellung, sondern ergibt sich aus dem Blockreward und dem Abstand der Halbierungen — sie lässt sich nicht nachträglich erhöhen, ohne die Regeln der Kette zu ändern.

Alle 12 000 Blöcke halbiert sich der Reward. Das wiederholt sich 37-mal, bis bei Block 444 000 die kleinste mögliche Einheit ausgeschüttet wird und die Ausgabe endet.

Es gab keinen Vorverkauf, keine Zuteilung an Gründer und keine reservierten Anteile. Jedes YSR, das existiert, wurde durch Rechenarbeit gefunden.

Was YSKAR nicht ist

Diese Liste steht hier, weil sie sonst niemand schreiben würde. Sie ist der ehrlichere Teil der Seite.

Keine Geldanlage

YSKAR hat keinen Preis, keinen Markt und keinen Gegenwert. Niemand kauft es dir ab. Es gibt kein Versprechen, dass sich das jemals ändert, und niemand sollte in der Erwartung minen, dass es das tut.

Noch nicht dezentral

Es gibt genau einen Knoten, der Blöcke annimmt. Die Rechenarbeit ist echt und nachprüfbar, aber wer diesen Knoten kontrolliert, kontrolliert die Kette. Unabhängige Knoten, die untereinander abstimmen, sind der nächste Schritt und noch nicht gebaut.

Ein Projekt, kein Produkt

YSKAR wird von einer Person entwickelt. Regeln können sich noch ändern, solange die Kette jung ist. Es gibt keine Garantie, dass sie in einem Jahr noch läuft.

Zwölf Wörter, keine Wiederherstellung

Deine Wallet hängt an zwölf Wörtern. Wer sie verliert, verliert sein Guthaben endgültig — es gibt keine Stelle, die sie zurücksetzen kann. Schreib sie auf Papier, bevor du anfängst.

Mining lastet den Prozessor aus. Das kostet Akku und Strom und erwärmt das Gerät. Wie viel, hängt vom Gerät ab — probier es kurz aus, bevor du es stundenlang laufen lässt.
